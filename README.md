# Goal-Based Budget Planner

## Project Overview
A Python application designed to help users manage their income, expenses, and savings goals.

## Planned Features
- Income tracking
- Essential and discretionary expense tracking
- Expense categories and subcategories using a Tree data structure
- Savings goal tracking
- Financial calculations
- SQLite database integration (proposed)

## Technologies
- Python
- SQLite (proposed)

## Project Status
Initial project setup. Implementation and task assignments are pending group discussion.
